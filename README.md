# カラオケビンゴ を GitHub Pages で公開する

`index.html` ひとつに 3×3・4×4・5×5 のすべてが入っています。
所要時間 約5分、git コマンドは使いません（すべてブラウザ上の操作）。
公開後、相手は **URLを開くだけ**。アカウントもアプリのインストールも不要です。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。3×3／4×4／5×5の切り替え込みでこれ1つ |
| `apple-touch-icon.png` | iPhone でホーム画面に追加したときのアイコン |
| `icon-192.png` / `icon-512.png` | Android・ブラウザ用のアイコン |
| `manifest.webmanifest` | アプリとして起動するための設定 |

## はじめて公開する場合

1. https://github.com/signup で無料登録（アカウントがあれば飛ばす）
2. https://github.com/new を開き、**Repository name** に `karaoke-bingo`、**Public** を選んで作成
3. **uploading an existing file**（または Add file → Upload files）に、上の5ファイルをまとめてドラッグ＆ドロップ → **Commit changes**
4. **Settings** → **Pages** → Source を `Deploy from a branch`、Branch を `main` / `(root)` にして **Save**
5. 1〜2分待って Settings → Pages を再読み込みすると URL が出ます

```
https://<あなたのGitHubユーザー名>.github.io/karaoke-bingo/
```

## すでに公開している場合（更新）

`index.html` と `manifest.webmanifest` を新しいものに差し替えるだけです。
Add file → Upload files で同名ファイルを上げると上書きされます。
1〜2分で全員に反映されます（URLは変わりません）。

> 以前 `4x4/` フォルダを追加していた場合、その中身はもう不要です。
> リポジトリの `4x4` フォルダ内の各ファイルを開いて、ゴミ箱アイコンから削除できます。
> 消さずに残しても動作に影響はありません。

## 相手に伝えるとよいこと

- **iPhone**：Safariで開く → 下の共有ボタン → **ホーム画面に追加**
  アプリのアイコンとして並び、次からはアドレスバーなしの全画面で起動します
- **3×3 / 4×4 / 5×5 はタイトル下のボタンで切り替え**。カードは別々に保存されるので、
  片方を遊んでいる途中でもう片方に切り替えても消えません
- **進行状況は各自のスマホに保存されます**。同じURLでも人それぞれ別のカードになります
- 音が出ます。うるさいときは画面右上のスピーカーボタンで消せます

## 遊び方

**カードを作る**

- **3×3** — マスをタップするたびに 87〜96点 のルーレットが回ります。同じ点数は出ません。
  8マスが埋まったら、残った2つから真ん中の点数を選びます（1つは出番なしになります）。
- **4×4** — 画面のどこかをタップすると16マスが一斉に回り、10秒かけて左上から順に止まります。
  点数は 87〜95点 で、同じ点数が重なることがあります。ビンゴは全10ライン。
- **5×5** — 4×4と同じ一斉ルーレット（25マス・10秒）。点数は 87〜94点。ビンゴは全12ライン。

4×4・5×5では、同じ点数がカードを占める数に上限があります。

| | 同じ点数 | 最高点だけ |
|---|---|---|
| 4×4 | 最大3マス | 95点は最大2マス |
| 5×5 | 最大5マス | 94点は最大4マス |

**マスを開ける**（モードで操作が違います）

- **3×3** — 開けたいマスをタップします。確認画面で「開ける」を押すと開きます。
- **4×4 / 5×5** — カラオケで出た点数を、盤の上の入力欄に打ち込んで「開ける」を押します。
  1曲につき1マスです。同じ点数のマスが複数あるときは、確認画面に縮小カードが出るので、
  開けたいマスを選んでから「開ける」を押します。

## 注意

Public リポジトリなので、中身（HTMLのソース）は誰でも見られます。
このアプリは個人情報を一切扱っていないので問題ありませんが、
パスワードなどを書き込まないでください。
